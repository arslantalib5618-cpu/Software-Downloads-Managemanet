# Software Downloads Management System

A Laravel-based Software Downloads Management System developed to manage software with a structured category system and newsletter functionality.

## Features

- Software CRUD (Create, Read, Update, Delete)
- Professional form validation
- Categories management
- Subcategories management
- Category & Subcategory system
- Newsletter subscription
- Email functionality for newsletter

## Technologies Used

- PHP
- Laravel
- MySQL
- Blade
- HTML
- CSS
- JavaScript
- Eloquent ORM

## Project Overview

This project was developed using Laravel to practice and demonstrate practical backend development skills.

The system includes complete Software CRUD functionality with professional form validation, along with a dynamic Categories and Subcategories system.

A newsletter section has also been implemented with email functionality for handling newsletter subscriptions.
